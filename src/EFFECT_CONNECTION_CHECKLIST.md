# Effect Connection Regression Checklist

## 목적

이 체크리스트는 이펙트 에디터, 스킬 설정, 시뮬레이터 간 연결 상태를 빠르게 검증하기 위한 문서입니다.

## 사전 준비

1. 앱 실행 후 설정 화면으로 이동한다.
2. 최소 1개의 스킬이 존재하는지 확인한다.

## A. 이펙트 에디터 -> 스킬 반영

1. 설정 > 그래픽 이펙트 화면으로 이동한다.
2. "프리셋 적용 대상 스킬"을 하나 선택한다.
3. 프리셋 라이브러리에서 임의 프리셋을 선택한다.
4. 기대 결과:

- 대상 스킬의 effectPresetId가 선택한 프리셋 id로 변경된다.
- 프리셋 색상/보조색/글로우/텍스처가 스킬 visual에 반영된다.
- 프리셋 종류에 따라 projectile 타입/속도/크기/유도/궤적 값이 동기화된다.

## B. 잠금/커스텀 모드

1. 대상 스킬에서 "프리셋 모드"를 잠금으로 설정한다.
2. 시뮬레이터에서 해당 스킬 이펙트를 발동한다.
3. 기대 결과:

- 프리셋 원본 값이 우선 적용된다.

4. 같은 스킬을 커스텀 모드로 전환한다.
5. 색상 또는 발광 값을 변경한다.
6. 시뮬레이터에서 다시 발동한다.
7. 기대 결과:

- 프리셋의 타입/패턴은 유지되며, 색상/발광/텍스처 커스텀 값이 반영된다.

## C. 스킬 상세 패널 동기화

1. 설정 > 스킬 화면에서 스킬 상세 패널을 연다.
2. 이펙트 프리셋을 변경한다.
3. 기대 결과:

- effectPresetId가 즉시 변경된다.
- visual 필드와 projectile 필드가 함께 업데이트된다.

## D. 최종 통합 확인

1. 스킬 화면에서 변경한 값이 그래픽 이펙트 화면에 동일하게 보이는지 확인한다.
2. 시뮬레이터에서 해당 스킬을 사용해 실제 이펙트 출력이 일치하는지 확인한다.
3. 앱을 새로고침하거나 데이터 입출력 후에도 값이 유지되는지 확인한다.
